Como jogar Tetris

  1. O tabuleiro tem 8x8 casas. Você recebe 3 peças por vez. Quando usar as três, aparecem mais três.
  2. Arraste uma peça até o tabuleiro e solte onde ela couber. As peças não podem ser giradas.
  3. Cada linha ou coluna preenchida some e vale {{ "{:,}".format(line_points).replace(",", ".") }} pontos. Completar várias de uma vez soma todas.
  4. Você tem {{ limit // 60 }} minutos. O jogo também acaba se nenhuma peça restante couber no tabuleiro.
