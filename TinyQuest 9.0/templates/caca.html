    Como jogar Caça-Palavras

    1. O tabuleiro tem {{ size }}x{{ size }} letras e {{ count }} palavras escondidas. A lista de palavras fica ao lado.
    2. As palavras estão na horizontal (da esquerda para a direita), na vertical (de cima para baixo) ou na diagonal (descendo para a direita). Nunca de trás para frente.
    3. Ao achar uma palavra, selecione todas as letras dela: clique nas letras ou arraste o dedo/mouse sobre elas.
    4. Aperte Checar. Se estiver certo, a palavra fica marcada na lista.
    5. Ache todas as palavras em até {{ limit // 60 }} minutos. O tempo começa assim que o tabuleiro aparece.
